# 要件定義書

| 項目 | 内容 |
|---|---|
| バージョン | 1.0 |
| 状態 | APPROVED |
| 承認日 | 2026-10-12 |

## 1. 目的・背景
他のアプリ（動画、ゲーム、レシピ、プレゼン資料など）を使いながら、経過時間を手早く測りたい。
既存の時計アプリへ切り替える手間なく、**クイック設定タイル 1 タップで画面上に小さなストップウォッチを出し、タップだけで開始・一時停止できる**ことで、作業を中断せずに時間計測できるようにする。

## 2. ターゲットユーザーと利用シーン
| ペルソナ | 利用シーン | 頻度 |
|---|---|---|
| 料理中のユーザー | レシピアプリを見ながら加熱時間を測る | 毎日 |
| 学習・作業中のユーザー | 教材/資料アプリを開いたまま作業時間を測る | 毎日 |
| 発表者・ゲーマー | プレゼンやゲーム画面の上で経過時間を確認する | 週数回 |

## 3. スコープ
### 3.1 対象（In Scope）
- 他アプリ上に重畳表示されるフローティング型ストップウォッチ（開始・一時停止のみ）
- クイック設定タイルによる表示 / 非表示の切り替え
- 表示中の画面常時オン
- 使い方説明画面（ランチャーから起動）

### 3.2 対象外（Out of Scope）
- リセット操作（非表示にする以外の方法）、長押し・ダブルタップ等の追加ジェスチャ
- ラップ / スプリット、カウントダウンタイマー、計測履歴、複数ストップウォッチ
- 通知・前面サービス（FGS）による常駐
- ロック画面上への表示
- 設定画面（サイズ・色・透過度などのカスタマイズ）
- ホーム画面ウィジェット、Wear OS 対応
- 使い方説明画面からの権限付与ボタン・タイル追加ボタン（Q-03 の回答により説明のみとする）

## 4. 機能要件
| ID | 要件 | 優先度 (Must/Should/Could) | 受入基準 |
|---|---|---|---|
| **REQ-001** | ストップウォッチ UI を他のアプリの上に重畳表示する | Must | Given 「他のアプリの上に重ねて表示」が許可済みで任意のアプリが前面にある When タイルで表示をオンにする Then そのアプリの上にストップウォッチ UI が表示され、UI の外側の領域は下のアプリをそのまま操作できる |
| **REQ-002** | クイック設定タイルから表示 / 非表示を切り替える | Must | Given UI が非表示 When タイルをタップ Then UI が表示されタイルがアクティブ状態になる / Given UI が表示中 When タイルをタップ Then UI が消えタイルが非アクティブ状態になる |
| **REQ-003** | 重畳表示の権限が無い状態でタイルが押されたら、権限の設定画面へ誘導する | Must | Given 「他のアプリの上に重ねて表示」が未許可 When タイルをタップ Then クイック設定パネルが閉じ、本アプリの「他のアプリの上に重ねて表示」設定画面が開き、UI は表示されず、タイルは非アクティブのまま |
| **REQ-004** | UI はフローティングアクションボタン程度の大きさの円形とする | Must | Given UI が表示中 Then UI は直径 64〜72dp の円形である（正確な値は UI 設計で確定） |
| **REQ-005** | UI のタップで計測の開始・一時停止を切り替える | Must | Given 表示直後（待機状態、`00:00`） When タップ Then 計測が開始される / Given 計測中 When タップ Then 一時停止し表示が止まる / Given 一時停止中 When タップ Then 止まっていた値から計測を再開する |
| **REQ-006** | 計測時間を mm:ss で表示し、60 分以上も時間単位を使わず分を加算する | Must | Given 経過 59 分 59 秒 When 1 秒経過 Then `60:00` と表示される / Given 経過 125 分 7 秒 Then `125:07` と表示される / Given 経過 9 分 5 秒 Then `09:05` と表示される（分は最低 2 桁、ゼロ埋め） |
| **REQ-007** | 計測の上限は `999:59` とする | Should | Given 計測中 When 経過時間が 999 分 59 秒に達する Then 表示は `999:59` で停止し、以降タップしても値は変わらない（非表示にするとリセットされる） |
| **REQ-008** | 1 秒未満は切り捨て、時間は端末起動からの経過時間を基準に測る | Must | Given 経過 1.999 秒 Then `00:01` と表示される / Given 計測中に画面消灯・スリープした When 復帰する Then スリープ中の時間も含めた経過時間が表示される |
| **REQ-009** | UI を非表示にすると計測がリセットされる | Must | Given 計測中または一時停止中（例: `03:21`） When タイルで非表示にし、再度表示する Then 待機状態の `00:00` から表示される |
| **REQ-010** | UI を表示している間は画面を常時オンにする | Must | Given UI が表示中（待機・計測中・一時停止のいずれも） When 端末の画面消灯タイムアウトを超えて無操作 Then 画面は消灯しない / Given UI を非表示にした When タイムアウトを超えて無操作 Then 通常どおり消灯する |
| **REQ-011** | UI をドラッグして移動できる | Should | Given UI が表示中 When UI をドラッグする Then UI が指に追従して移動し、計測状態は切り替わらない / When 指の移動量がしきい値未満で離す Then タップとして扱われる（REQ-005） |
| **REQ-012** | UI の表示位置を記憶し、画面内に収める | Should | Given 初めて表示する Then 画面右端・縦中央付近に表示される / Given UI を移動してから非表示にした When 再度表示する（アプリ再起動後を含む） Then 前回の位置に表示される / Given 画面回転などで位置が画面外になる When 表示 Then 画面内に収まる位置へ補正される |
| **REQ-013** | 待機・計測中・一時停止中を見た目で区別できる | Should | Given 各状態 Then 背景色（Material 3 / ダイナミックカラー）が状態ごとに異なり、一目で区別できる（一時停止中の点滅などの詳細は UI 設計で確定） |
| **REQ-014** | タップ時に短い触覚フィードバックを返す | Should | Given UI が表示中 When タップして状態が切り替わる Then 短い振動（ハプティクス）が発生する |
| **REQ-015** | 画面消灯・ロック中も計測を継続する | Must | Given 計測中 When 電源ボタンで消灯・ロックし、時間をおいてロック解除する Then UI が再び表示され、消灯中も含めた経過時間が表示される（ロック画面上には表示しない） |
| **REQ-016** | 表示中に権限が取り消された、またはプロセスが終了した場合は非表示と同じ扱いにする | Must | Given UI が表示中 When 「他のアプリの上に重ねて表示」の許可を取り消す、またはアプリのプロセスが終了する Then UI は消え、タイルは非アクティブ表示になり、次回表示時は `00:00` から始まる |
| **REQ-017** | ランチャーから起動すると使い方説明画面を表示する | Must | Given アプリアイコンをタップ Then 使い方説明画面が表示され、(1) クイック設定へのタイルの追加方法 (2) 「他のアプリの上に重ねて表示」の許可が必要であること (3) タップで開始/一時停止、ドラッグで移動、非表示でリセット、が説明されている |
| **REQ-018** | タイルの名称とアイコン | Should | Given クイック設定の編集画面 Then タイル名が「ストップウォッチ」（英語環境では「Stopwatch」）、アイコンがタイマーを表す絵柄で表示される |

## 5. 非機能要件
| ID | カテゴリ | 要件 | 測定方法 |
|---|---|---|---|
| **NFR-001** | 権限（最小化） | ユーザーに許可を求める権限は `SYSTEM_ALERT_WINDOW` のみとする。前面サービス・通知・`WAKE_LOCK`・`VIBRATE`・`INTERNET` 等の権限は宣言しない（常時オンはウィンドウフラグ、触覚はビューのハプティクスで実現）。ライブラリが自動付与するアプリ内部用の signature 権限は除く | マージ済みマニフェストの検査（テスト / CI） |
| **NFR-002** | 互換性 | Android 12 (API 31) 以上で動作、targetSdk 36 | CI / エミュレータ（API 31 と最新 API） |
| **NFR-003** | アクセシビリティ | TalkBack で UI の状態と経過時間が読み上げられ、タップ操作できる。タッチ領域は 48dp 以上 | Compose UI テスト（semantics）/ 手動 |
| **NFR-004** | 正確性 | 表示値と実経過時間（端末起動からの経過時間基準）の差が常に 1 秒未満。計測中の表示更新間隔は 1 秒以内 | 偽の時計を使ったユニットテスト |
| **NFR-005** | 性能 | タイルのタップから UI 表示まで 500ms 以内（Pixel 6 相当） | 手動計測 / Journey |
| **NFR-006** | 省電力 | 表示の再描画は秒の変化時のみ行い、毎フレーム再描画しない。非表示時はタイマー処理を一切行わない | コードレビュー / ユニットテスト |
| **NFR-007** | ローカライズ | 日本語と英語に対応（既定リソースは英語） | リソース検査 / スクリーンショット |
| **NFR-008** | プライバシー | ネットワーク通信・データ収集を行わない。永続化するのは UI 位置のみ | マニフェスト検査 / コードレビュー |

## 6. 制約・前提
- Jetpack Compose / Material 3（重畳ウィンドウ内の UI も Compose で実装する）
- 配信: Google Play（`com.puzzroom.quickstopwatch`）
- 前面サービスは使用しない（Q-01）。表示中のオーバーレイを持つプロセスはシステムに高優先度で扱われる前提とし、万一終了された場合は REQ-016 の挙動とする
- 重畳表示の種別は `TYPE_APPLICATION_OVERLAY`。仕様上ロック画面の上には表示されない

## 7. 用語集
| 用語 | 定義 |
|---|---|
| UI / フローティング UI | 他アプリの上に重ねて表示される円形のストップウォッチ表示 |
| タイル | クイック設定パネルに置く本アプリのタイル |
| 表示 / 非表示 | タイル操作による UI の出し入れ。非表示 = 計測リセット |
| 待機状態 | 表示直後で計測を一度も開始していない状態（`00:00`） |
| 計測中 / 一時停止中 | 時間が進んでいる状態 / タップで止めた状態 |
| 重畳表示の権限 | 「他のアプリの上に重ねて表示」（`SYSTEM_ALERT_WINDOW`） |
